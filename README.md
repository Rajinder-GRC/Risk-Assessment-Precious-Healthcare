# Risk Assessment: Precious Healthcare Center (Simulated Project)

A self-directed cybersecurity risk assessment of a fictional clinic in Grand Rapids, Michigan, created to practice GRC skills. No real organization or data is involved.

## What I did
- Assessed 11 assets for confidentiality, integrity, and availability needs
- Scored each risk on Likelihood x Impact (25-point scale)
- Identified threats, vulnerabilities, and recommended controls
  (preventive, detective, corrective)
- Built Excel pivot table for analysis
- Wrote a summary report with prioritized recommendations

## Key finding
High-confidentiality assets carried the highest average risk (16/25),
so patient data, email, and logins should be protected first.
